# プライバシーポリシー

本サイト「絆上げ計算機」（以下「本サイト」）は、利用者のプライバシーを尊重し、個人情報の保護に関する法律（個人情報保護法 / APPI）および EU 一般データ保護規則（GDPR）の趣旨に沿って運営しています。

最終更新日: 2026年11月2日

## 1. 本サイトが収集しない情報

本サイトは、以下の情報を **一切収集しません**。

- 氏名、メールアドレス、電話番号、住所等の連絡先情報
- アクセス解析ツール（Google Analytics 等）によるトラッキングデータ
- 第三者広告ネットワークによる広告識別子
- ログインに利用した Google アカウントのメールアドレス・表示名・プロフィール画像等（ログイン機能については 2.3 を参照）

## 2. 本サイトが取り扱う情報

### 2.1 入力データ

利用者が画面に入力した数値や生徒名・衣装名等は、計算のためにブラウザおよびサーバーで処理されます。これらはゲーム内データであり、利用者本人を識別する情報を含みません。

入力内容の自動保存および「絆ランク管理」の内容は、利用者のブラウザのローカルストレージ（localStorage）に保存され、本サイトのサーバーには保存されません。ブラウザのサイトデータを削除すると消去されます。ただし、ログインした利用者の「絆ランク管理」の内容は、2.3 のとおりサーバーにも保存されます（ログイン中もブラウザのローカルストレージに同じ内容を保存するため、ログアウト後もそのブラウザには残ります）。

### 2.2 アクセスログ

本サイトをホスティングしているサービス（Render 社）および配信に用いている CDN（Cloudflare 社）は、サービスの提供および不正アクセス防止のため、訪問者の IP アドレス・User-Agent・アクセス日時等を一時的にログとして保持する場合があります。これは各事業者のプライバシーポリシーに従って管理されます。

- Render プライバシーポリシー: https://render.com/privacy
- Cloudflare プライバシーポリシー: https://www.cloudflare.com/privacypolicy/

### 2.3 ログイン（任意）

「絆ランク管理」の内容を複数の端末・ブラウザで使うため、Google アカウントでログインできます（任意）。ログインした場合、本サイトは以下の情報をサーバーのデータベースに保存します。

- ログインに使用したサービスの種類（Google）と、Google が発行する利用者ごとのID（英数字の識別子）
- 初回ログイン日時・最終ログイン日時
- 「絆ランク管理」の内容（衣装ごとの絆ランク）

ログイン時に Google から受け取るのは上記のIDのみで、メールアドレス・表示名・プロフィール画像等は受け取らず、保存もしません。これらの情報は、以下の目的にのみ使用し、第三者に提供しません。

- 「絆ランク管理」の保存・読み込み
- 本サイトの改善のための統計（利用者数、絆ランクの分布等）の作成。統計は個人を特定しない形で集計し、集計結果を公開する場合は、個々の利用者のデータが分からない形でのみ公開します。

ログイン時の認証は Google の画面で行われ、Google のプライバシーポリシーに従います。

- Google プライバシーポリシー: https://policies.google.com/privacy

## 3. Cookie の利用

本サイトは、ログイン（2.3）した利用者のログイン状態を保持するため、およびログイン処理中の一時的な情報を保持するために Cookie を1つ使用します（有効期間は最長180日。ログアウトすると削除されます）。ログインしない利用者には、ログイン処理を開始しない限り Cookie を発行しません。

管理者画面 (`/admin/*`) でも同じ Cookie をログインセッション保持に使用します。

## 4. 第三者サービスへのリンク

本サイトには、不具合・要望報告のため以下の外部サービスへのリンクがあります。リンク先での情報の取り扱いは各サービスのプライバシーポリシーに従います。

- Google Forms（報告フォーム）
- X (旧 Twitter)（運営者アカウント）

## 5. 利用者の権利

ログインした利用者は、「絆ランク管理」ページの「アカウントを削除」から、2.3 の情報をいつでも削除できます。ログインしていない利用者については、本サイトは利用者を特定する情報を収集していないため、開示・訂正・削除等の請求対象となるデータを保有していません。投稿されたプリセットの修正・削除を希望する場合は、本ページ末尾の問い合わせ先までご連絡ください。

## 6. お問い合わせ

本サイトに関するお問い合わせ、プリセットの修正依頼等は、サイト上部に記載の報告フォームまたは X アカウントまでお願いします。
