# プライバシーポリシー

本サイト「絆上げ優先度計算機 / 贈り物配分シミュレータ」（以下「本サイト」）は、利用者のプライバシーを尊重し、個人情報の保護に関する法律（個人情報保護法 / APPI）および EU 一般データ保護規則（GDPR）の趣旨に沿って運営しています。

最終更新日: 2026年11月1日

## 1. 本サイトが収集しない情報

本サイトは、以下の情報を **一切収集しません**。

- 氏名、メールアドレス、電話番号、住所等の連絡先情報
- アクセス解析ツール（Google Analytics 等）によるトラッキングデータ
- 第三者広告ネットワークによる広告識別子
- Cookie を用いた利用者識別（ユーザーログイン機能は存在しません）

## 2. 本サイトが取り扱う情報

### 2.1 入力データ

利用者が画面に入力した数値や生徒名・衣装名等は、計算のためにブラウザおよびサーバーで処理されます。これらはゲーム内データであり、利用者本人を識別する情報を含みません。

入力内容の自動保存および「絆ランク管理」の内容は、利用者のブラウザのローカルストレージ（localStorage）にのみ保存され、本サイトのサーバーには保存されません。ブラウザのサイトデータを削除すると消去されます。

### 2.2 アクセスログ

本サイトをホスティングしているサービス（Render 社）および配信に用いている CDN（Cloudflare 社）は、サービスの提供および不正アクセス防止のため、訪問者の IP アドレス・User-Agent・アクセス日時等を一時的にログとして保持する場合があります。これは各事業者のプライバシーポリシーに従って管理されます。

- Render プライバシーポリシー: https://render.com/privacy
- Cloudflare プライバシーポリシー: https://www.cloudflare.com/privacypolicy/

## 3. Cookie の利用

本サイトは、エンドユーザー向けには Cookie を発行しません。

管理者画面 (`/admin/*`) ではログインセッション保持のために Cookie を1つ使用しますが、これは管理者のみが利用する画面です。

## 4. 第三者サービスへのリンク

本サイトには、不具合・要望報告のため以下の外部サービスへのリンクがあります。リンク先での情報の取り扱いは各サービスのプライバシーポリシーに従います。

- Google Forms（報告フォーム）
- X (旧 Twitter)（運営者アカウント）

## 5. 利用者の権利

本サイトは利用者を特定する情報を収集していないため、開示・訂正・削除等の請求対象となるデータを保有していません。投稿されたプリセットの修正・削除を希望する場合は、本ページ末尾の問い合わせ先までご連絡ください。

## 6. お問い合わせ

本サイトに関するお問い合わせ、プリセットの修正依頼等は、サイト上部に記載の報告フォームまたは X アカウントまでお願いします。
